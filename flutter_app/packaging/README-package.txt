TaskScheduler 0.1.2（Windows x64）
==================================

这是 TaskScheduler 的便携版 Windows 程序包。解压后运行 taskscheduler.exe 即可启动。

Flutter 界面通过 ts_bridge.dll 调用共享 C 内核，提供任务规划、会话管理、模型连接设置、甘特图和结构化时间表编辑功能。Windows runner 提供自绘标题栏、窗口缩放和统一关闭处理。

时间表数据在发送分析请求前由应用和 C 内核共同校验。无效或冲突的数据会显示错误，不会作为有效约束继续排程。

首次使用时，在应用设置中配置兼容的模型连接和本机凭据。发行包不应包含个人 API 密钥或本机配置文件。
