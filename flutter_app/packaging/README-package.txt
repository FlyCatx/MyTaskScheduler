TaskScheduler 0.5.0（Windows x64）
===============================

解压发行包后运行 taskscheduler.exe。应用通过 ts_bridge.dll 调用本地 C 内核；
离线 OCR 辅助程序位于 data\ocr\ocr_host.exe，无需安装 Python 或 Tesseract。

主要功能
--------
- 从文字、文档和扫描件提取任务，使用用户配置的模型服务生成计划，并在本地校验。
- 编辑任务依赖、周时间表和跨日时段；查看排程、冲突建议和甘特图。
- 只读导入 ICS 日历，将外部占用计入可用时间。
- 记录任务执行时间，查看耗时回顾并导出 CSV。
- 对长材料进行分块分析，在提交计划前预览结果。

0.5.0 更新
----------
- 任务详情浮窗自适应高度，长任务只滚动正文，标题与操作区常驻。
- 回顾支持共享年月日历选择与“应用”范围；耗时文案区分无记录、未知、零投入与待校正。
- 统一新菜单、筛选项和对话框按钮样式；回顾固定在顶部，OCR 与分块分析移入输入区“＋”。
- OCR 帮助与校对页精简，文件选择默认只列 PDF / PNG / JPG / JPEG。
- 日程编辑简化：开始/结束用日历、时区改为可搜索城市列表；侧栏日程新增一周时间轴、事件详情与关联任务。
- 甘特冲突弹窗去重；任务执行新增开始/暂停/继续/结束，到达计划截止后按 5＋5 分钟规则提醒并自动完成。
- Windows 系统通知可在正文打开任务，并通过按钮延长或结束；通知不可用时以应用内操作兜底。

0.4.0 更新
----------
- 新增全局共享日程：可选关联会话、重复/例外、时间表与甘特叠层、运行期提醒。
- 日程忙碌对所有会话的排程生效；普通/分块分析在日程变化时拒绝迟到结果。
- 备份/恢复包含日程；提醒仅应用运行时有效，退出后不承诺送达。

0.3.1 更新
----------
- 分块分析先给出预览，确认后才生成计划；可排除候选任务，材料或版本变化会使预览失效。
- 修正“分析结束后未真正提交却提示成功”的问题；提交结果与失败原因更明确。
- 分块来源引用改用材料中的真实引用；无法核验的任务进入待确认，不伪造来源。
- 接通 Windows 锁屏/睡眠事件：暂停计时并标记待校正，恢复后不自动继续。
- 备份包含 OCR 来源信息；恢复时校验路径、大小与 SHA-256，旧备份仍可读。
- 清理账户页与关于页的禁用占位入口，不再显示看似可用的未接入操作。
- 0.3.0 的布局、通知、OCR、分块和排程改进保持不变。

配置与数据
----------
首次使用时在设置中填写模型服务地址、模型名称和凭据。发行包不包含 API 密钥。
应用数据保存在 TaskSchedulerData。升级前请备份该目录；0.3.1 可打开 0.2.x
数据。回退旧版时请恢复升级前的数据备份。

已知限制
--------
窗口圆角外缘可能仍有轻微像素阶梯，标题栏右键系统菜单尚不可用。OCR 识别质量
取决于扫描件；真实手写、公式、竖排和复杂多栏文档未全面验证。完全退出应用时
没有常驻服务，执行截止提醒依赖应用运行或最小化；周视图暂不支持拖拽改期和月视图。

完整版本历史见仓库根目录的 CHANGELOG.md。
