# Flutter 桌面界面

本目录包含 TaskScheduler 的 Windows 桌面用户界面，使用 Flutter 与 Dart 构建。它提供任务规划的主要交互界面，让用户输入文本或添加文档、查看和整理生成的任务，并在任务列表、依赖关系图与工时视图之间切换。

## 模块职责

- 展示会话、任务计划、任务详情和分析状态。
- 提供文本与文档输入、任务编辑、筛选、设置和本地会话管理。
- 通过 FFI 桥接调用共享的 C 核心，完成模型通信、计划校验、依赖分析、排序与导出。
- 在界面层呈现核心返回的数据；任务的业务校验与调度规则由 C 核心负责。

应用仅整理和展示计划，不会执行任务或运行模型生成的命令。

## 目录结构

- `lib/main.dart`：应用入口。
- `lib/src/app/`：启动流程和应用装配。
- `lib/src/ffi/`：与原生 C 桥接库通信。
- `lib/src/model/`：界面和状态层使用的数据模型。
- `lib/src/state/`：会话、设置、计划和文档输入相关状态管理。
- `lib/src/ui/`：页面、主题和通用界面组件。
- `test/`：Flutter 单元与界面测试。
