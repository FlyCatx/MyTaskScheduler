# C 核心模块

本目录包含 TaskScheduler 的 C 语言核心与平台适配层，为桌面界面提供任务分析、计划校验、排序和结果导出能力。核心逻辑由 Win32 程序和 Flutter 桌面界面共享。

## 模块组成

- `app/`：应用入口与运行流程的组织。
- `bridge/`：面向 Flutter FFI 的 C 接口，负责请求、状态查询、取消和数据交换。
- `domain/`：文本输入处理、计划校验、依赖分析、调度、展示数据和导出逻辑。
- `state/`：配置文件与本地配置状态的读写。
- `platform/`：Windows 凭据、文件、运行时和文本相关接口。
- `util/`：核心代码共用的基础工具。

领域逻辑与界面实现分开：界面通过桥接层提交输入并读取结果，业务校验和计划计算在 C 核心中完成。相关 ABI 数据以稳定的结构化格式交换，并由桥接接口管理缓冲区生命周期。
